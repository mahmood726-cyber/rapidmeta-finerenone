The runner **prints which gates it skipped** in `--fast`. A scoped pass that does not name its

**Exit codes are four, not two.** `0 PASS · 1 FAIL · 2 VACUOUS · 3 BROKEN`. VACUOUS blocks the
push: a gate that never reached the case it was built for is more dangerous than one that
objected, because it reads as a pass.

## The seven

Every row below: the plant, the observed failure, the restoration, and the assertion that the
gate saw its case. All four are re-run mechanically by `gates/verify_gates_can_fail.py` — **7/7
plants tripped their gate, 7/7 restored to PASS.**

### 1 — Named-positive regression for trial identity

`gates/gate1_trial_identity.py`. Authority is **ClinicalTrials.gov, read by this lane**, not our
store: NCT01617096 carries `acronym: "ASPIRE"` and names MTN-020; NCT01539226 is IPM 027,
sponsor International Partnership for Microbicides — The Ring Study.

**It found a live defect.** `agyw-hiv-prep-review` has the pair **swapped at six sites**
(`inputs.trials[0..1].label`, `results.by_outcome.primary.per_trial[0..1].label`,
`risk_of_bias.by_outcome.primary.NCT*.trial`). Ceftaroline's FOCUS 1 / FOCUS 2 pair is correct
and serves as the built-in negative.

- **plant** — swap the *ceftaroline* labels in memory → CONFIRMED 4→0, findings 6→10, exit 1
- **restore** → findings 6, exit 1
- **repair** — correct the AGYW swap in memory → **exit 0**, the gate can reach PASS
- **hide** — drop the AGYW object, simulating an upstream filter → **exit 2 VACUOUS**, 2/4 seen,
  0 findings and *not* a pass
- **saw its case** — 4/4 named registrations reached; control **0/12 false positives**

Three distinct exit codes from one gate on real objects.

### 2 — Known-negative control, mandatory

`gates/textmatch.py` + `gates/gate2_textmatch_control.py`. `ControlledCount.value` **raises**
until a known-negative set has been run. You cannot obtain the number without measuring how
often the matcher is wrong.

**Measured on real pages**, task "does this page confirm trial *X* contributes", ground truth
from the store:

| matcher | sensitivity | false positives |
|---|---|---|
| naive — token anywhere on the page | 126/126 | **6/378 = 1.6 %** |
| contiguous — registration within 300 chars | 126/126 | **1/378 = 0.3 %** |

The naive false positives sit on pages of **median 70,455 characters against a corpus median of
46,185**. The confounder is printed beside the rate, because that is the diagnosis.

Enforcement is a **ratchet**: 215 in-scope text-matching checks, 27 controlled, **188 frozen**.
A new one fails the gate.

- **plant** — a real new file `gates/__planted_uncontrolled_check.py` → FAIL, named
- **exemption path** — same file with `# no-control: <reason>` → PASS
- **restore** — file removed → PASS, backlog 188/188/0 new
- **saw its case** — 10/10 hand-built shape probes correct, control 0/6

**A first draft of this reported 739 of 820 modules.** `i += 1` counted as a count and `x in
dict` as text matching. A gate that fires on 90 % of a repository is bypassed on day one — reach
reported as population, inside the gate written to stop that.

### 3 — One authoritative reason field

`gates/reason.py` + `gates/gate3_one_reason_field.py`. Seven spellings. Three surfaces already
implemented three different precedences, one of them **reasoned about only in a 30-line comment**
in `outputs/_baseline_projector.py` that the other two readers never saw.

Declared: one precedence, one reader `not_pooled_reason()`. **No data renamed** — 152 objects
carry `poolable_reason` and unifying them is Mahmood's call, as `field_aliases.py` already
records. Escalated.

Kinds before counts, and the number moved by an order of magnitude when they were enumerated:

| kind | n |
|---|---|
| identical text under two names | 91 |
| subset — a summary, not a contradiction | 9 |
| cross-reference — "see poolable_reason" | 7 |
| **DIVERGENT** — two substantive different answers | **11** |

A first pass scoring any multi-name outcome reported **118**. `withdrawn_note` and `card_note`
are annotations, not aliases; counting them adds 26 false divergences.

- **plant** — a contradictory `withdrawn_reason` on a clean outcome → 11→12, exit 1
- **repair** — collapse every divergence onto its authority → **exit 0**
- **saw its case** — control 0/8, positive control fires, named positive **pinned to blob
  `c623a213`**

**The pin exists because `--repair` broke the gate.** The named positive was the live
`attr-pn-review/primary`; repairing it made the case unreachable and the gate went VACUOUS
forever. *A control that retires itself at the moment of success is not a control.*

### 4 — A stored judgement must reference what it judged

`gates/gate4_judgement_reference.py`. **2,789 stored judgement blocks:**

| kind | n | what it can say when its subject moves |
|---|---|---|
| A VERSIONED — hash, snapshot or commit | **40** | **STALE** |
| B TIMESTAMPED — when, not what | 1,397 | NOT-CHECKABLE |
| C IDENTIFIER — an NCT: a *mutable* subject | 868 | NOT-CHECKABLE |
| D NOTHING | 484 | NOT-CHECKABLE |

**1.4 % of the judgements in this corpus can be re-checked against their own subject.** The right
column is demonstrated, not asserted: `prove_undetectable()` mutates one subject and shows what
each kind reports.

The fix is one line at the point of writing — `block['subject_ref'] = subject_ref({…})`.

- **plant** — a new judgement with no reference → FAIL, backlog 484→485, 1 NEW
- **repair** — give every kind-D a `subject_ref` → PASS, re-checkable **1.4 % → 20.5 %**
- **saw its case** — 4/4 classifier probes; control 0/6

**Scoring only the judgement's own dict returned kind A = 0**, with 191 `stored_judgement_at_
derivation` fields in the corpus. An implausible proportion is a statement about the instrument;
ancestors count.

### 5 — No irreversible action on an absence-defined set

`gates/absence.py` + `gates/gate5_absence_defined_set.py`. **Imports the shipped selector** from
`scripts/retire_2026_08_28.py` rather than re-implementing it — a gate that re-implements what it
checks is a tautology.

> **absence-defined selector: 756. Positive restatement: 2. Unexplained: 754.**

The gate does **not** claim 754 pages have results. It claims nobody established that they do
not — which is larger, and is what was one command from being served.

**And it found a page the selector gets wrong.** `PREDICTION_MODEL_KFRE_REVIEW.html` states
`0.88 (95% CI 0.86–0.90)` with an **en-dash**. The shipped regex accepts `to`, `,` and `-` and
not an en-dash, so the page sat in the removal set as having "no interval anywhere in its text".
One character.

- **plant** — `--action`, an actual removal attempt → **FAIL**, refused
- **standing run** — reports both counts, refuses nothing → PASS
- **saw its case** — the KFRE page, or exit 2
- **control 1/6 = 16.7 % measured false-positive rate**, printed. `"the risk of bias assessment
  is not pooled across domains"` matched my positive regex. **The direction is stated: a false
  positive inflates the positive count and therefore SHRINKS the gap, so 754 is a lower bound.**

### 6 — NCT beside every trial name, at the generator

`gates/gate6_nct_beside_name.py`. Three arms: the generator (AST), served prose, and the swap
regression. `build_app_v2.py`'s contributing-trials row already does the right thing and prints
`no registry identifier` when there is none — a stated absence is a correct answer.

- **15 of 18** generator render sites name a trial with no registration in the same fragment
- **136 of 136** trial names in served prose do carry a registration within 300 chars
- **Arm C, the regression:** AGYW **SWAPPED ×2**, ceftaroline **AGREES ×2** — the same detector,
  opposite answers, on real pages
- **plant** — a generator site emitting a bare name → 17→18, exit 1
- **saw its case** — both pinned registrations; control **0/9**

**Two of my own errors, both caught by instruments rather than by re-reading:**
1. Arm C sat inside arm B's acronym loop. That filter admits neither `ASPIRE / MTN-020` (a
   slash) nor `The Ring Study` (lower case), so **neither named positive was ever seen and the
   gate exited VACUOUS** — the exact failure it was built for, caught by the harness.
2. A 300-character window reported **all four** pinned trials as swapped, including the correct
   ceftaroline pair, because both names sit inside one table. Page layout read as content. Arm C
   had shipped **with no control of its own**; it has one now, keyed to the correct pair. The
   fix is pairing on the rendering convention (name-then-registration) within a **derived**
   120-character radius — the longest separator this corpus emits is
   ` &mdash; https://clinicaltrials.gov/study/` at 43 characters.

### 7 — Blast radius before a class-wide edit

`gates/gate7_blast_radius.py`. `ssot/build_tabbed.py` **radius = 155 topics.** The
acknowledgement must state the number, so it cannot be given without having been shown it.

- **plant** — an unacknowledged change → FAIL, "verifying it on one object is a claim about 1/155"
- **correct ack** (`155`) → PASS
- **wrong ack** (`15` — the incident's own under-count) → **FAIL**
- **saw its case** — `build_tabbed.py` and a topic-owned file; control 0/4

**The first derivation gave `build_tabbed.py` a radius of SIX**, because it mentions six topic
ids in special-case branches. Membership of the build closure decides; naming a topic never
narrows a build module. *The file looked specific because it named specific things* — which is
the same reasoning that let a per-page brief edit a class-wide generator. A self-check now
asserts each build root comes out at the full corpus size.

## What a PASS means here, exactly

Four gates fail on the corpus as it stands, for real reasons. Their findings are **frozen by
name** and pointed at their escalation; the gates refuse anything new.

| gate | frozen | meaning |
|---|---|---|
| 1 trial identity | 6 sites | the AGYW swap, escalated |
| 2 text-match control | 188 modules | uncontrolled matchers |
| 3 reason divergence | 11 outcomes | escalated |
| 4 judgement reference | 484 sites | kind D |
| 5 selector miss | 1 page | the KFRE en-dash |
| 6 bare name / swap | 15 / 2 | generator sites / served swaps |

**A PASS from a ratcheted gate means NO NEW INSTANCES. It does not mean clean, and both numbers
print on every run.** A hook that blocks every push on a pre-existing backlog is bypassed within
a day, and a bypassed gate still reads as protection.

## What remains discipline — the honest list

1. **`absence.py` is not called by any removal script.** Gate 5 refuses under `--action`, but a
   script that never imports the module is unaffected. **This is the biggest remaining gap**: the
   precondition is available, not operative — the exact distinction the pre-commit hook already
   warns about.
2. **Nothing writes `subject_ref`.** Gate 4 stops *new* bare judgements and demonstrates the fix;
   retrofitting 484 kind-D and 868 kind-C judgements is unstarted.
3. **The reason data is not unified.** Only the reader is single. 152 objects still carry
   `poolable_reason`; escalated as Mahmood's decision.
4. **Gate 2's scope is a naming convention** (`gate_|check_|lint_|audit_|sweep_|verify_…`, plus
   all of `gates/`). A text matcher inside a module named something else is not covered. Narrow
   and enforceable was chosen over broad and ignored, and that is a real limit.
5. **Gate 6 arm B is reported, not enforced.** 15 bare generator sites are frozen, not fixed.
6. **Gate 7 covers `ssot/` only.** `outputs/_baseline_projector.py` is a projector gate 6 reads
   and gate 7 does not weigh.
7. **The pre-push hook only runs in clones that set `core.hooksPath .githooks`.** CI is the
   backstop.
8. **Gate 5's positive-restatement regex has a measured 16.7 % false-positive rate.** Left
   un-tuned deliberately: tuning against the validation sample burns the only measurement of the
   instrument I own.
9. **I hand-wrote every known-negative control.** The labeller is the classifier's author, which
   is a real weakness and is recorded as one rather than quietly dropped.
