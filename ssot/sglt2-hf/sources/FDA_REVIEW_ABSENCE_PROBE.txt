FDA REVIEW-DOCUMENT ABSENCE PROBE -- dapagliflozin (NDA 202293) and empagliflozin (NDA 204629)
Run 2026-08-10 by _probe_farxiga_letters.py and _probe_fda_hf_supplement.py.

WHY THIS FILE EXISTS. Four cascade cells record regulator_fda as FOUND at the
approved LABEL rather than at a review document, and the object states that no
review is published for the heart-failure indications. That is an ABSENCE claim,
and an absence claim with nothing behind it is an assumption. This is what was
actually asked of the server, and what it answered.

METHOD. Every approval letter Drugs@FDA serves for the application was read off
the overview page; each letter names one or more submissions; a review table of
contents was requested for each submission by name. A submission derived from a
letter the page serves is a submission that provably exists, which is the line
between discovery and invention.

RESULT, dapagliflozin NDA 202293: 21 approval letters, 29 submissions probed,
exactly TWO publish a review table of contents -- s000 (2014, the original
diabetes application) and s024 (2021), whose own cover page names chronic kidney
disease as the indication under review. The heart-failure supplements s021 and
s028 publish letters and labels and no review.

RESULT, empagliflozin NDA 204629: the overview page lists exactly one review
table of contents, for s000 (2014), and it returns 404. Confirmed twice, by two
independent routes.
