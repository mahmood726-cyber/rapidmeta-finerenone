Run 2026-08-10. Every query below was actually executed on that date and its

================================================================================
1. THE LIVING-SEARCH DEFECT THIS RECORD EXISTS TO DOCUMENT
================================================================================

A drug-name-keyed ClinicalTrials.gov query CANNOT rediscover FAIR-HF2, which is
the largest and most recent ferric carboxymaltose outcome trial in this review.

Query actually run (2026-08-10), API v2:

  query.cond      = heart failure
  query.term      = AREA[InterventionName]("ferric carboxymaltose" OR
                    "ferric derisomaltose" OR "iron isomaltoside" OR
                    "intravenous iron" OR "iron sucrose" OR "ferumoxytol")
  filter.advanced = AREA[DesignAllocation]RANDOMIZED

  RESULT: 35 studies, 8 with enrolment >= 300. NCT03036462 (FAIR-HF2) ABSENT.

The reason, read off the staged registry record NCT03036462.ctgov.json:

  INTERVENTION: DRUG | Iron   | (no other names)
  INTERVENTION: DRUG | Saline | (other name: "salin")

The registry record names the drug only as "Iron". The trial is COMPLETED,
PHASE4, RANDOMIZED, condition heart failure -- it passes a status filter, a
phase filter and an allocation filter, and is still invisible, because no brand
name and no INN appears in its intervention field at all.

This matters beyond one trial. The shared-defect note for this batch attributes
missed trials to COMPLETED-only filters, hardcoded drug whitelists and wrong
population ontologies. None of those three explains this miss. A search keyed on
ANY drug name -- however complete the whitelist -- misses this trial.

Corrected query, also run 2026-08-10, keyed on the intervention CLASS:

  query.cond      = heart failure
  query.intr      = iron
  filter.advanced = AREA[DesignAllocation]RANDOMIZED

  RESULT: 52 studies. REDISCOVERY TEST, all five trials this review contains:

    FOUND NCT03036462 FAIR-HF2    COMPLETED n=1105
    FOUND NCT02937454 AFFIRM-AHF  COMPLETED n=1132
    FOUND NCT02642562 IRONMAN     COMPLETED n=1160
    FOUND NCT03037931 HEART-FID   COMPLETED n=3065
    FOUND NCT01453608 CONFIRM-HF  COMPLETED n=304

A search that cannot re-derive the review's own membership is not a completeness
check, so this rediscovery test is the evidence behind this object's completeness
statement rather than an assertion that a search was run.

Note that the corrected query carries NO status filter and NO comparator
requirement. A placebo requirement would exclude IRONMAN, whose comparator is
usual care; a COMPLETED-only filter would drop the four ongoing trials below.

4. THE ONE CELL THAT COULD NOT BE SOURCED, AND EVERY PLACE IT WAS LOOKED FOR
================================================================================

HEART-FID's top secondary endpoint -- time to first cardiovascular death or
hospitalisation for heart failure -- has a PRESPECIFIED DESIGN that is fully
verified here, and a RESULT that no staged layer prints.

VERIFIED, from the trial's own protocol and statistical analysis plan, posted by
ClinicalTrials.gov and staged as CTGOV_HEARTFID_PROT_SAP.extract.txt:

  "8.7.1 Top Secondary Comparison: Time to first event of cardiovascular death
   or hospitalization of heart failure ... The Cox proportional hazards model
   will be employed to conduct this comparison."
  "Section 5.3.2: updated alpha for top secondary to 0.04 based on FDA feedback."

An alpha of 0.04 on the top secondary is why an interval on this endpoint is a
96% interval and not a 95% one. That is now a sourced design fact rather than a
plausible-sounding inference -- but it is the DESIGN, not the RESULT.

Retrieval attempts for the effect estimate itself, all made 2026-08-10:

  New England Journal of Medicine full text ... paywalled; Europe PMC reports
      isOpenAccess N, inEPMC N, no PMC identifier
  ClinicalTrials.gov posted results ......... NCT03037931 posts THREE outcome
      measures, all the components of the hierarchical primary, and NO analysis
      block on any of them: deaths 131 vs 158, HF hospitalisations 297 vs 332,
      6MWT change 8.179 vs 3.979. No hazard ratio is posted.
  FDA label, Injectafer NDA 203565 s027 ..... section 14.2 is the only heart
      failure efficacy section and it rests entirely on CONFIRM-HF's 6-minute
      walk distance. A scan of the whole label for the strings "hazard",
      "rate ratio", "odds ratio", "risk ratio", "win ratio" and "relative risk"
      returns NOTHING. The regulator holds no clinical-event estimate for this
      molecule at all.
  Trial protocol and SAP ..................... design only, as above
  American College of Cardiology trial summary  prints proportions 31.0% versus
      32.2% and the words "not significant"; prints neither the ratio nor its
      bounds, so it cannot yield the cell
  Europe PMC open-access corpus .............. searched for open full texts
      carrying both "HEART-FID" and "96%"; 33 hits read down, none restates the
      estimate

So the effect is NOT STORED. What is stored is the endpoint, its prespecified
rank, its model, its alpha and therefore its interval level, together with this
record of where it was looked for. An estimate available only through a summary
that prints neither the ratio nor its interval is exactly the "a value is not a
cell" trap this batch has already been caught by more than once.

5. REGULATOR LAYER -- WHAT EACH AGENCY ACTUALLY HOLDS
================================================================================

UNITED STATES, ferric carboxymaltose (Injectafer, NDA 203565, label revised
01/2025, staged as FDA_LABEL_INJECTAFER.extract.txt). There IS a heart failure
indication and it is narrower than a reader would guess:

  "iron deficiency in adult patients with heart failure and New York Heart
   Association class II/III to improve exercise capacity."

Section 14.2 "Iron Deficiency in Heart Failure" rests on ONE trial, CONFIRM-HF,
and on ONE endpoint, the 6-minute walk distance. FAIR-HF, CONFIRM-HF and
AFFIRM-AHF appear elsewhere in the label only in the SAFETY section, as a pooled
exposure of 1,016 patients against 857. No clinical-event effect estimate for
any endpoint appears anywhere in the document.

UNITED STATES, ferric derisomaltose (Monoferric, NDA 208171 s003, staged as
FDA_LABEL_MONOFERRIC.extract.txt). The string "heart failure" does not occur in
the label at all. The indication is iron deficiency anaemia only.

EUROPE. Neither product is centrally authorised, so no European Public
Assessment Report exists to check. Probed 2026-08-10:

  .../medicines/human/EPAR/ferinject ......... HTTP 404
  .../medicines/human/EPAR/monofer ........... HTTP 404
  EMA site search, scripted request .......... HTTP 401

Ferinject was registered through the DECENTRALISED procedure (SE/H/1816/001/DC,
from 6 July 2007), which produces national marketing authorisations and national
public assessment reports rather than an EPAR. What the EMA does hold for this
molecule class is a completed Article 31 referral on intravenous
iron-containing medicinal products, staged here as
EMA_IV_IRON_ART31_ANNEX1.pdf, which concerns hypersensitivity risk and carries
no efficacy assessment of any heart failure endpoint.

So the European layer is recorded not_available for every efficacy cell in this
object, and the reason is a fact about the AUTHORISATION ROUTE rather than about
the agency's silence.
