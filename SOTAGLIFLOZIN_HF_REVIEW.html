    The synthesis's stated combined sample size is consistent with this object's denominators for the trial they share, given the four other trials it names.

What this object corrects

  • the supplied first-event estimate for the worsening-heart-failure trial
    This object was handed a time-to-first estimate for that trial to carry, described as unverified.
    It matches no analysis in the staged regulator review. The review reports two time-to-first estimates for that trial, on the two ascertainment bases, and the supplied figure is neither of them; its lower bound is the lower bound of one of them. Both real estimates are stored, the supplied one is stored nowhere.
  • which layer holds the time-to-first analysis at all
    The handoff expected the registry to be searched for it.
    Neither registry posts it. Every posted outcome on both records is a total-occurrence or a change-from-baseline analysis. The quantity exists in exactly one staged document, the regulator's statistical review, which is recorded on each cell.
  • the European regulator layer
    The handoff recorded that the European application was withdrawn, which suggested an application for this indication that failed.
    The European authorisation was GRANTED, in 2019, and for a different indication entirely -- an adjunct to insulin in type 1 diabetes. The staged medicine overview does not contain the phrase heart failure at all. It was later withdrawn at the holder's request for commercial reasons. So the European layer is not available for this endpoint because the EU authorisation was for type 1 diabetes and was withdrawn -- which is a different and more informative fact than a withdrawn application. What this object does NOT say, and what an earlier version of this sentence did say, is that there was never a European heart-failure assessment. The staged documents cannot establish that: an overview that omits a phrase is not a record of what was never filed. The corrected-claims block already made exactly that distinction, and this sentence had been contradicting it.

What could not be resolved

  • no independent synthesis checks the values in this object
    Four dated queries found no synthesis reporting either trial's own primary endpoint as a separate row, and the closest class-level network meta-analyses do not name either trial in their abstracts, so their included-study lists cannot be read from what is open. The consequence is stated plainly rather than minimised: the per-cell values here rest on the publication, the registry and the regulator, and on no independent re-analysis. A synthesis may exist behind a paywall or under indexing these queries did not reach.
  • what explains the regulator-versus-publication divergences
    Both total-occurrence cells differ between the FDA documents and the agreeing publication and registry -- on the lower bound for the smaller trial, on the point estimate for the larger. Within the FDA the two documents agree with each other on BOTH trials: an earlier version of this entry said they differed on the larger one, which was this object's own error and is corrected in the corrected-claims block. Nothing in the staged sources explains it. The review describes its analyses as based on investigator-reported events in all randomized patients, which is where an explanation would start, but the staged text does not say that it accounts for these differences and this object does not assert that it does.
