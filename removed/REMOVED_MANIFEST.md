# REMOVED / QUARANTINED apps — RapidMeta identity-resolution 2026-07-06

These live public apps were built on **contaminated or absent primary sources** with **no truthful single drug-as-lead pivotal trial** (class/topic/procedure network meta-analyses, placeholder tokens, or legacy generics only ever used as a comparator arm). They cannot be made honest by a count re-derivation, so the truth-first action is removal.

**This removal is fully REVERSIBLE and git-tracked.** The app HTML files were **moved (not deleted)** from the repo root into `removed/`, and all `index.html` cards / E156-claim-map entries / `sitemap.xml` URLs were stripped. To restore an app: `git mv removed/<APP>.html <APP>.html` and revert the index/sitemap edits (see the de-list commit).
