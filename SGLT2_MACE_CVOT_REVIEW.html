SGLT2 inhibitors versus placebo, three-point MACE in type 2 diabetes: this review's pooled estimate is withdrawn

This page previously served a pooled estimate for this question. That estimate has been withdrawn. The original page is preserved byte for byte and is linked below; nothing has been deleted.

No pooled estimate stands for this question. This page publishes none: the previously served pool has been withdrawn and nothing replaces it.

What is withdrawn

The pooled estimate OR 0.9074 (95% CI 0.831 to 0.9908) across two trials, and the claim of a statistically significant reduction that its interval carried by excluding no effect.

Whether the finding survives this withdrawal

It does not. This is not a presentational correction, a re-rendering, or a restatement of the same result in different terms. The estimate is withdrawn because the object that produced it records, in the same outcome, that the quantities required to make it meaningful were never established.

Why — quoted from the review's own stored record

The object underlying this page holds, in the same outcome block that carried the pooled value:

pool_uniformity.effect_measure[0] "NOT ESTABLISHED" pool_uniformity.estimand[0] "NOT ESTABLISHED" THE_POOL_IS_REFERRED_2026_08_20.state "REFERRED, NOT WITHDRAWN"

And its stated warrant for pooling the trials at all reads, verbatim:

"The extractor recovered a pooled result from this page, so the page pooled these trials."

The page was its own justification. The reason recorded for combining these trials is that a pooled number had already appeared on this page. No source outside this project's own prior output was consulted for it. A conclusion whose only warrant is that it was previously published cannot support a claim about the world, and the interval above should not have been read as evidence of an effect.

Two further properties of the withdrawn estimate, recorded in the same object:

  • Neither contributing trial carried a provenance tier, and neither stored the sentence its effect value was read from. The object states of itself that it was recovered from the published page, with protocol, search, screening log, risk-of-bias assessment, certainty rating and sources absent from the source.
  • The measure pooled was an odds ratio, for an outcome the contributing trials analysed as time to first event and report as a hazard ratio. Converting a survival endpoint to an odds ratio discards the time dimension the trials analysed.

Trials absent from the withdrawn pool

The withdrawn estimate pooled two trials. A published systematic review already cited by this review — Kluger et al. 2018, Cardiorenal Outcomes in the CANVAS, DECLARE-TIMI 58, and EMPA-REG OUTCOME Trials — names three, and CANVAS was not among the two pooled here. A re-derivation of the question additionally reaches VERTIS-CV.

What is currently known, and what is not published

A protocol-faithful re-derivation of this question, built from a protocol registered before it ran and using only values fetched from trial registrations, reaches four trials and gives, under the pre-declared estimator and interval method:

HR 0.9159 (95% CI 0.8242 to 1.0178) — which does not exclude no effect.

THAT RE-DERIVATION IS NOT PUBLISHED AND IS NOT PROMOTED. It has not cleared review and is stated here only so that this withdrawal is not read as implying the opposite result is established. The claim is withdrawn; no replacement claim is being made in its place. A withdrawal that quietly substitutes an unpublished number would repeat, in the other direction, the error being corrected.
