"""A PAGE SERVING AN EXTERNAL BENCHMARK WHERE ITS OWN RESULT BELONGS.

    "The number was real and belonged to somebody else."

THE CLASS, and why it is worse than a wrong number. A wrong number is at least OURS -- it was
computed from trials this review holds, by a method this review can name, and it is refutable by
recomputing it. A published benchmark rendered in the slot a result belongs in is refutable by
nothing on the page, because the page contains no trace of where it came from. The reader sees a
value under this project's name, on this project's index, beside this project's trial count, and
there is no arithmetic anywhere in the object that produces it.

THE TWO CONFIRMED INSTANCES, both found by hand and both now corrected on their cards:

    COLCHICINE_CVD   card `HR 0.75 (0.61-0.91), k=2`. Declared in PUBLISHED_META_BENCHMARKS.json
                     as `benchmark_type: self_reference`, source COLCOT + LoDoCo2, method DL
                     random-effects. The object's own pool was 0.7940 (0.6750-0.9339) at k=5.
    DOAC_AF          card `HR 0.81 (0.73-0.91), k=4`. It was Ruff 2014's published risk ratio,
                     which that page carries as its COMPARATOR. The object's pool was 0.7817.

AND THE COLCHICINE BENCHMARK DOES NOT RECONCILE WITH ITS OWN DECLARED SOURCE EITHER, which is a
second and independent failure: it states `N: 11816` where COLCOT (4,745) plus LoDoCo2 (5,522) is
**10,267**, out by 1,549; and its two named trials pool to 0.7215 (0.6243-0.8338) against a served
upper bound of 0.91, out by **seven and a half units in the last quoted place**.

WHY A SWEEP AND WHY NOW. Two instances found by hand is not a measurement. The shape is entirely
mechanical -- a served headline that equals the BENCHMARK and not the object's own pool -- so the

THE THREE LIMBS

CARD_RE = re.compile(
    r'<a href="(?P<page>[A-Za-z0-9_]+\.html)" class="card [^"]*">'
    r'<span class="name">[^<]*</span><span class="pub">(?P<pub>.*?)</span></a>')

# A served triple, in either register the cards are authored in. `Pooled:` writes
# `0.8715 (0.7461 to 1.018)`; `Published:` writes `0.25 (0.19&ndash;0.33)`.
NUM = r"(-?\d+(?:\.\d+)?)"
TRIPLE_RE = re.compile(
    NUM + r"\s*\(\s*(?:95%\s*(?:CI|CrI)\s*)?" + NUM + r"\s*(?:to|&ndash;|&#8211;|–|-)\s*"
    + NUM + r"\s*\)")
K_RE = re.compile(r"\bk\s*=\s*(\d+)")

VERDICTS = ("CARD_IS_THE_BENCHMARK", "CARD_IS_THE_OBJECT", "CARD_IS_NEITHER",
            "CARD_WITHDRAWN", "CARD_CARRIES_NO_ESTIMATE", "NO_CARD", "NO_OBJECT",
            "NO_BENCHMARK", "OBJECT_HAS_NO_POOL")


def _f(x):
    try:
        return float(x)
    except (TypeError, ValueError):
        return None


def parse_card(pub):
    """(register, point, lo, hi, k) from a card's published text."""
    txt = pub or ""
    reg = ("withdrawn" if "withdrawn" in txt.lower()
           else "published" if txt.strip().lower().startswith("published")
           else "pooled" if txt.strip().lower().startswith("pooled")
           else "other")
    m = TRIPLE_RE.search(txt)
    kk = K_RE.search(txt)
    if not m:
        return reg, None, None, None, (int(kk.group(1)) if kk else None)
    return (reg, _f(m.group(1)), _f(m.group(2)), _f(m.group(3)),
            int(kk.group(1)) if kk else None)


def object_pool(obj):
    """(point, lo, hi, k, outcome_id, per_trial) for the object's OWN headline, or Nones.

    THE HEADLINE OUTCOME IS READ FROM A DECLARATION, NEVER GUESSED. `project_index_cards.py`
    records why: on IV_IRON_HF, `sorted(results)[0]` is all-cause mortality, and taking it would
    silently compare a card against a different outcome's value. A multi-outcome object with no
    declared headline is REFUSED here for the same reason.
    """
    results = ((obj.get("results") or {}).get("by_outcome")) or {}
    if not results:
        return (None,) * 5 + (None,)
    declared = ((obj.get("results") or {}).get("headline_outcome")
                or obj.get("headline_outcome"))
    if declared and declared in results:
        oid = declared
    elif len(results) == 1:
        oid = next(iter(results))
    else:
        return (None,) * 5 + (None,)
    res = results[oid] if isinstance(results[oid], dict) else {}
    pooled = res.get("pooled") or {}
    if pooled.get("withdrawn"):
        return (None, None, None, res.get("k"), oid, res.get("per_trial"))
    return (pooled.get("point"), pooled.get("ci_low"), pooled.get("ci_high"),
            res.get("k"), oid, res.get("per_trial"))


def close(a, b, d=2):
    """Does a agree with b AT THE PRECISION b IS SERVED TO? One unit in the last place.

    The card serves two decimals; the object stores sixteen. Comparing them at full precision
    asks whether two different roundings of one quantity are bit-identical, which is the defect
    this project just spent an hour removing from another gate.
    """
    if a is None or b is None:
        return False
    return abs(float(a) - float(b)) <= (10.0 ** -d) + 1e-12


def classify(card, obj_pool, bench):
    reg, cp, clo, chi, ck = card
    op, olo, ohi, ok, _oid, _pt = obj_pool
    if reg == "withdrawn":
        return "CARD_WITHDRAWN"
    if cp is None:
        return "CARD_CARRIES_NO_ESTIMATE"
    is_obj = close(cp, op) and close(clo, olo) and close(chi, ohi)
    is_ben = (bench is not None and close(cp, bench.get("pooled"))
              and close(clo, bench.get("lci")) and close(chi, bench.get("uci")))
    if is_ben and not is_obj:
        return "CARD_IS_THE_BENCHMARK"
    if is_obj:
        return "CARD_IS_THE_OBJECT"
    if op is None:
        return "OBJECT_HAS_NO_POOL"
    return "CARD_IS_NEITHER"


def benchmark_reconciles(bench, obj):
    """Does the BENCHMARK triple follow from the OBJECT'S OWN trials? Bound, not enumeration.

    THE FIRST VERSION OF THIS LIMB WAS WRONG IN THE FAMILY THIS PROJECT KEEPS FINDING, and its
    eight "findings" were mostly its own. It took whichever outcome the object declared as its
    headline and compared the benchmark against THAT, without ever asking whether the two were
    measuring the same thing:

        INCRETIN_HFpEF  benchmark is an HR for a worsening-HF / CV-death composite. The object's
                        declared headline is `kccq_css_change` -- a MEAN DIFFERENCE in a symptom
                        score, per-trial 7.8 and 6.9. Exponentiating those against a hazard ratio
                        produced a "pool" of 7.4901 and a gap of 21.9, and it was reported as a
                        benchmark that does not reconcile.
        IV_IRON_HF      benchmark is an HR. The object's declared headline is a RATE_RATIO over
                        RECURRENT events. The object DOES hold a matching HR outcome
                        (`hfh_cvd_first`, 0.7957) and this limb never looked for it.

    That is P36 and P37 one level up: TWO QUANTITIES WERE COMPARED BY THEIR SLOT RATHER THAN BY
    THEIR DEFINITION, and the arithmetic completed without complaint. So the limb now refuses
    unless the comparison is a comparison:

      MEASURE   the benchmark's estimand must equal an object outcome's measure, and exactly one
                outcome must carry it. Zero or several -> NOT_ASSESSABLE, named.
      SCOPE     the benchmark's k must equal that outcome's k. A benchmark synthesising a
                DIFFERENT SET OF TRIALS is not supposed to reproduce from this one, and asking
                whether it does is not a question about the corpus. ARNI's benchmark is
                PARADIGM-HF's own published hazard ratio against an object pooling four trials.

    AND THE COST OF THAT HONESTY IS NAMED: this limb can no longer convict COLCHICINE_CVD, whose
    benchmark is k=2 against an object holding three trials. That conviction came from testing
    the benchmark against ITS OWN DECLARED SOURCE -- COLCOT and LoDoCo2, named in the record with
    their PMIDs -- which is a different test and one this limb cannot perform, because a
    benchmark record generally does not say which trials it pooled.
    """
    if not bench or bench.get("estimand") not in ("HR", "RR", "OR"):
        return "NOT_ASSESSABLE", "the benchmark is not a ratio measure"
    results = ((obj or {}).get("results") or {}).get("by_outcome") or {}
    want = bench.get("estimand")
    cands = []
    for oid, blk in results.items():
        if not isinstance(blk, dict):
            continue
        pooled = blk.get("pooled") or {}
        if str(pooled.get("measure") or "").upper() == want and not pooled.get("withdrawn"):
            cands.append((oid, blk))
    if not cands:
        return ("NOT_ASSESSABLE",
                "MEASURE MISMATCH: the benchmark is a %s and no live outcome on this object "
                "carries that measure. Comparing them would compare two different quantities."
                % want)
    if len(cands) > 1:
        return ("NOT_ASSESSABLE",
                "%d outcomes carry the measure %s and the benchmark names no outcome id, so "
                "WHICH ONE it should be compared against is a guess. Refused."
                % (len(cands), want))
    oid, blk = cands[0]
    bk, ok = bench.get("k"), blk.get("k")
    if bk is not None and ok is not None and int(bk) != int(ok):
        return ("NOT_ASSESSABLE",
                "SCOPE DIFFERS: the benchmark synthesises k=%s and this object's `%s` pools "
                "k=%s. A synthesis of a different trial set is not expected to reproduce from "
                "this one, and a mismatch here would be a fact about the two scopes."
                % (bk, oid, ok))
    th, se = [], []
    for t in (blk.get("per_trial") or []):
        if not isinstance(t, dict):
            continue
        s = G.se_from_ci(t.get("ci_low"), t.get("ci_high"), t.get("ci_level"))
        if s and t.get("point"):
            th.append(math.log(float(t["point"])))
            se.append(s)
    if len(th) < 2:
        return "NOT_ASSESSABLE", "fewer than two per-trial estimates carry a usable interval"
    v, why = G.assess_joint(bench.get("pooled"), bench.get("lci"), bench.get("uci"), th, se)
    return v, "outcome `%s`, measure %s, k=%s. %s" % (oid, want, ok, why)

def selftest():
    sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8", errors="replace")
    fails = []

    def check(name, got, want):
        ok = got == want
        print("  %-70s %s  %r" % (name, "ok" if ok else "FAIL", got))
        if not ok:
            fails.append(name)

    print("1. THE PARSER READS BOTH REGISTERS THE CARDS ARE ACTUALLY AUTHORED IN:")
    check("`Pooled: HR 0.8715 (0.7461 to 1.018), k=4`",
          parse_card("Pooled: HR 0.8715 (0.7461 to 1.018), k=4"),
          ("pooled", 0.8715, 0.7461, 1.018, 4))
    check("`Published: PFS HR 0.25 (0.19&ndash;0.33), k=2`",
          parse_card("Published: PFS HR 0.25 (0.19&ndash;0.33), k=2"),
          ("published", 0.25, 0.19, 0.33, 2))
    check("a withdrawal is its own state, never an estimate",
          parse_card("Estimate withdrawn &mdash; the four trials measure four DIFFERENT")[0],
          "withdrawn")

    print("\n2. THE GUARD CAN FIRE, ON THE REAL CASE THAT SHIPPED (P16's fourth clause).")
    print("   COLCHICINE_CVD's card as served before it was withdrawn:")
    card = parse_card("Published: HR 0.75 (0.61&ndash;0.91), k=2")
    pool = (0.7940, 0.6750, 0.9339, 5, "primary", None)
    bench = {"pooled": 0.75, "lci": 0.61, "uci": 0.91, "estimand": "HR"}
    check("card is the BENCHMARK, not the object", classify(card, pool, bench),
          "CARD_IS_THE_BENCHMARK")

    print("\n3. AND DOES NOT FIRE WHEN THE CARD IS THE OBJECT'S OWN POOL:")
    own = parse_card("Pooled: HR 0.7940 (0.6750 to 0.9339), k=5")
    check("card is the OBJECT", classify(own, pool, bench), "CARD_IS_THE_OBJECT")

    print("\n4. AND WHEN THE CARD IS NEITHER, IT SAYS SO rather than picking one:")
    other = parse_card("Published: HR 0.55 (0.30&ndash;1.00), k=4")
    check("card matches neither", classify(other, pool, bench), "CARD_IS_NEITHER")

    print("\n5. COMPARISON IS AT THE PRECISION THE CARD IS SERVED TO, not at float precision:")
    check("0.75 against a stored 0.7500000001", close(0.75, 0.7500000001), True)
    check("0.75 against 0.7940 is NOT close", close(0.75, 0.7940), False)
    check("a missing side is never 'close'", close(None, 0.75), False)

    print("\n6. A MULTI-OUTCOME OBJECT WITH NO DECLARED HEADLINE IS REFUSED, never guessed:")
    two = {"results": {"by_outcome": {"acm": {"pooled": {"point": 0.978}},
                                      "hhf": {"pooled": {"point": 0.8066}}}}}
    check("two outcomes and no headline_outcome -> no pool read", object_pool(two)[0], None)
    one = {"results": {"by_outcome": {"acm": {"pooled": {"point": 0.978}}}}}
    check("one outcome is unambiguous and IS read", object_pool(one)[0], 0.978)

    print("\n7. THE LIVE CORPUS -- and a zero here would make this file meaningless:")
