eye. The figures are authored at 720 user units wide and are double-column
figures, so they display at 150 mm. At that width one unit is 0.2083 mm, and the
journal's 8 pt floor is therefore 13.5 units. Every text element on every figure

8.9 pt.

    s = open(path, encoding="utf-8").read()
    if old not in s:
        raise SystemExit("ANCHOR MISSING (%s) in %s" % (tag, path))
    n = s.count(old) if count == -1 else count
    open(path, "w", encoding="utf-8").write(s.replace(old, new, n))
    N[0] += n
    print("  %-52s x%d" % (tag, n))
